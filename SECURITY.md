# Política de seguridad
- Usa únicamente código propio o expresamente autorizado.
- No introduzcas claves privadas, frases semilla, tokens ni secretos.
- Este MVP no despliega ni modifica contratos en mainnet.
- La ausencia de hallazgos no demuestra ausencia de vulnerabilidades.
- Las ejecuciones de Slither deben moverse a workers aislados antes de uso compartido: contenedores efímeros, límites de CPU/memoria/red/procesos y filesystem desechable.
- Reporta vulnerabilidades del producto de forma privada al mantenedor.
